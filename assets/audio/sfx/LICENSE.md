# Sound effects licence

Every file in this folder was made by `tools/sfx/build.py` for this project. Each sound is designed from
the sources below: cut, pitched, layered, filtered and mixed into new sounds, together with sound made
from code (filtered noise, crackle, sub-bass). All of it can ship in the commercial game.

| Source | Used for | Licence |
| --- | --- | --- |
| VSCO 2 Community Edition by Versilian Studios (Sam Gossner), github.com/sgossner/VSCO-2-CE | Timpani, giant drums, bass drums, cymbals, gongs, tuba, trombones, horns, trumpets, strings, metal and glass hits, scrapes, chains, bubbles, zaps | CC0 1.0 (public domain). Credit is asked for, not required. |
| FluidR3_GM sound font by Frank Wen | Sampled choir ("Aahs", "Oohs") | MIT |
| Kokoro-82M by hexgrad, via kokoro-onnx | The bosses' spoken lines and the cries of enemies, processed into creature voices | Apache-2.0 |
| Code in tools/sfx | Noise, crackle, sub-bass, filters, reverb | Original work of this project |

The voices come from a text-to-speech model, which is AI-generated audio. Declare it in Steam's AI content
disclosure, as the narrator voice already is.
